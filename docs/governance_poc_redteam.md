# 观察层 Red-Team 压力测试 PoC 治理补充协议

> **修订记录 v0.2（2026-08-22）**：输出契约从「4 字段反方包（target_thesis/risk_carrier/counter_logic/uncertainty_level）+ 4 栏紧凑视图」升级为「红方→蓝方→裁判 三节点 + 红蓝裁审查记录」，理由：引入蓝方事实抗辩与裁判独立终审，弥补单角色空头质检员无辩护方、无终审评分的结构缺口。拓扑仍为单向线性管道（非多轮辩论），禁用表达库与 INVALID_ROUND 兜底机制保留。

## 1. 范围与边界
* **系统定位**：本模块属于 observation 观察层独立子模块，与生产交易决策系统物理隔离。
* **数据单向流**：仅接收每日生成的 `os2_report`（`output/memo_{date}.html`）作为输入，禁止开放自由外网检索与未经清洗的噪音信源。
* **零生产权限**：本模块输出仅作为《Red-Team 审查记录》归档于观察层目录 `output/redteam_records/`，禁止自动介入交易打分、调仓与下单指令。
* **事件驱动挂钩**：由 `os2_report.write()` 写盘成功后自动触发（`os_layers/redteam_trigger.py`），产出即触发；子进程异常/超时一律吞掉，不阻塞主链路。开关 `REDTEAM_HOOK_ENABLED=0` 可一键熔断。

## 2. 外部框架集成挂起规则
* **vnpy 执行层**：保持挂起状态。解锁前提为 H1 高股息策略（2026-08-21 预注册版本）完成既定观察窗口并通过 Gate 评估，且经评估确认人工下单已构成系统性瓶颈。初期即便接入，亦仅限信号推送模式。

## 3. 红队质量门槛（前置硬规则）
管线拓扑：`红方 Red Team Lead → 蓝方 Blue Team Defender → 裁判 Judge`，各节点输出必须严格遵守 JSON Schema，任一节点缺失要素即判定为 `INVALID_ROUND`（至多重试 1 次后丢弃为占位记录，不进入人工观察视图）。

| 节点 | 必填字段 | 硬卡校验标准 |
|---|---|---|
| 红方 | `status` / `attack_points[]`(id, dimension, claim, evidence_and_logic) | attack_points 数量须为 2~4；dimension 限枚举（宏观/资金/产业/技术/安检闸门/仓位风控）；id 不重复；字段非空 |
| 蓝方 | `status` / `defense_points[]`(attack_id, stance, counter_evidence, residual_risk) | 必须覆盖红方全部 attack_id；stance 限枚举（完全化解/规则对冲/部分承认/无法化解）；字段非空 |
| 裁判 | `status` / `score` / `verdict` / `rationale` / `key_risk_watch` | score 须为 0~100 数值；verdict/rationale/key_risk_watch 非空 |

*禁用表达库*：包含"注意市场波动"、"政策存在不确定性"、"未来走势需观察"等无指向性泛化语句的输出，直接视为校验失败。

## 4. 输出呈现格式（Red-Team 观察层审查记录）
系统生成后按以下结构渲染为 Markdown，人工阅读耗时控制在 60 秒内：
1. **元信息**：日期 / Target Memo / Status（VALID 或 INVALID_ROUND）
2. **原始备忘录核心裁决**：最终裁决 / 建议仓位 / 主线候选（规则式从 memo 提取，提取不到不阻断）
3. **红方攻击点清单**：每条含 维度 + 漏洞陈述 + 攻击推导
4. **蓝方抗辩与对冲依据**：每条对应 attack_id，含 立场（完全化解/规则对冲/部分承认/无法化解）+ 事实证据 + 残余风险
5. **裁判终审评分与判定**：综合评分(0~100) / 裁决结论 / 终审评语 / 盘中关键观察点

## 5. PoC 评估与关闭判据
* **试验周期**：连续 20 个交易日。
* **评估指标**：
  * **结构有效率** = (Status=VALID 的记录数 / 总运行记录数)
  * **反驳有效度** = (人工复盘确认提供有效下行预警或阻断无效决策的记录数 / 总入库记录数)
* **关闭条件**：
  * 运行 20 个交易日后，若结构有效率低于 50%，终止 PoC。
  * 若反驳有效度趋近于零（纯形式噪音）或反方建议导致决策摩擦过大而无正向收益，终止 PoC。
  * 未经正式治理评审，严禁延长试验周期或直接并入主链路。
