# P0-A 完成报告：封住「静默错误通道」

> 日期：2026-09-03
> 目标：让系统具备「宁可失败，也绝不悄悄产出错误结果」的能力
> 基线 commit：adc62a8（清理前）

## 一、改了什么（全部最小化、只读审计后落地）

### 1. 退出码真实化（P0-A1）
| 文件 | 改动 |
|---|---|
| `backend/daily_collect.py` | 新增后置完整性校验 `verify_completeness()`（针对目标交易日的 stock_daily / stock_flow_daily 行数判定「部分采集失败」）；`CRITICAL_STEPS` 集合；`__main__` 失败走 `sys.exit(1)`，关键步失败 `critical_ok=False` |
| `backend/build_derived_tables.py` | `run_build` 失败 `rc!=0` 计入失败；整脚本失败时 `return 1`（原恒 return 0） |
| `backend/run_brain_report.py` | `brain.run()` 返回 `ok=False`（含降级层数）时 `sys.exit(1)` |

### 2. fail-fast（P0-A2）
`backend/run_daily.py`：
- `STEPS` 改为四元组 `(name, script, retries, critical)`。
- `step1 数据采集 / step1b 技术回填 / step1b2 派生表补齐 / step2 八层决策树 / step2b 决策简报 / step2b2 Ledger` 标 `critical=True`。
- 关键步失败即 `break`，打印中断原因与跳过清单，绝不继续。

### 3. stale-date 保护（P0-A3）
`backend/brain/cio_agent.py`：
- 新增 `StaleCacheError`。
- `_load_data()` 加载 `brain_report.json` / `decision_tree.json` 后，强制校验其 `trade_date == _report_date()`（当前数据最新日）。不符即抛异常 → `produce()` 传播 → `push_daily.py` 以非零退出。

### 4. market_daily 空壳清理（P0-A4）
- `backend/build_market_daily.py`：新增 `has_source()` 守卫，无可用 A 股成交额源（早期历史 amount=0 / 换板日无数据）的日期**跳过，绝不写 NULL 空壳行**。
- `backend/database/collector.py`：akshare 抓取整体失败（涨跌家数全 0 且成交额全 0）时跳过保存。
- 清理：8678 行 NULL 空壳（`1990-12-19`~`2026-07-09`）已备份至 `market_daily_shell_backup_20260903` 并删除，剩 39 真实行、0 残留。审计清单见 `backend/database/market_daily_shell_cleanup_manifest_2026-09-03.json`（含 snapshot_id / source_commit / row_count / checksum）。

### 5. 故障注入测试（P0-A5）
`backend/tests/test_pipeline_failure_visibility.py`：**2 passed**。
- 测试①：完整性校验失败 → `daily_collect` 退出码决策非零。
- 测试②：step1 注入失败 → `run_daily` 在 step1 中断、跳过决策树/brain/推送、`brain_report.json` 未被重写、且单独调用 `produce()` 因 stale 被拒（`StaleCacheError`）。

## 二、故障注入验证结果（模拟 TDX 失败）

```
daily_collect 失败 → rc=1 → run_daily 在 step1 中断
  → 跳过 step2 决策树 / step2b 决策简报（不生成新 brain）
  → 跳过 step3 推送
  → brain_report.json 保持旧缓存、mtime 不变
  → 即便单独触发 push_daily，cio_agent._load_data() 抛 StaleCacheError
    → push_daily 非零退出，旧数据不会被渲染成当日备忘录推送
```

08-31 类型事故通道已关闭。
