> 配套文档：docs/themarketmemo_kb.md（知识库）
> 日期：2026-09-01
> 定位：所有"缺口"均为**观察层候选**，受 Phase 1E 冻结 + 8 周纪律期约束（禁新指标/禁改风控/禁分数优化）。落地须走 freeze-then-build / Release Gate，不得直接接生产评分。

## 我们 OS 的现有骨架（对齐用）

- 八层决策树：L0 宏观 → L1 全球资金 → L2 中国周期 → L3 产业趋势 → L4 题材共识 → L5 龙头体系 → L6 交易机会 → L7 风险预算 → L8 交易模式复盘
- brain package：market data → Asset Intel → Research Memory → Validation → Decision/CIO（L1-L7）
- 观察链：market_momentum.py（TheMarketMemo xlsx composite = 0.2*RS20+0.4*RS60+0.4*RS120）、fetch_market_sheets.py（外部信号，独立存观察链不动生产）
- 四维健康仪表盘：Prediction Quality / Transmission Fidelity / Evidence Quality / Adaptation Safety
- A股方法论红线：板块>龙头>资金>图形；候选只圈不筛；禁 amount/ma20/ma60 个股过滤；买卖人工定
- 治理边界：动量模块仅外部交叉验证不参与决策；TheMarketMemo/tradecat 每日拉取存观察链

## 二、可增补缺口（按优先级）

### P0 — 高杠杆、低风险、直接对齐现有观察链

**G1. 宏观20图接入观察层（L1 / narrative_engine L1 扩展）**
- 内容：铜金比→PPI、油金比→CPI、信用利差、AAII/NAAIM 情绪、标普/纳指 COT、板块强度。
- 现状：narrative_engine L1 正计划扩展"比特币/原油/全球基金资金流向"，macro20 是其天然补全。
- 数据可得性：macromicro.me（20charts 直链）、可经 akshare/东财补 A 股侧宏观。
- 动作：在观察层新增 `macro_20_observation`，**只读不评分**，与现有 momentum 并列。
- 门禁：需 Release Gate（新增外部数据源）；不碰生产。

**G2. 市场宽度口径对齐（观察层 ↔ market_daily）** — ✅ 已完成（2026-08-31）
- 内容：核对我们 `market_daily` 宽度口径是否 = "收盘价高于 MA20/50/200 百分比"；若不同，在观察层补一份 TheMarketMemo 口径（85/15 顶底、50 牛熊分界）做交叉验证。
- 风险：我们红线禁个股 ma20/ma60 过滤，但**观察层用指数级宽度**不违规（对象是全市场指数，非个股筛选）。
- 动作：写 `breadth_cross_check.py`（观察层），输出两口径差异日志，不进生产。
- 产出：`backend/observation/breadth_cross_check.py` + `output/breadth_cross_check_2026-08-31.md/.json`。**关键发现**：两口径定义不同互补；且 `market_daily.up_count` 历史仅 37 交易日（2026-07-10 起），远浅于 MA 位置宽度（可回溯 2024-05-28，551 日），AD 宽度回补前不作长期 regime 参照。

### P1 — 中杠杆、需结构化（框架内化，非新数据）

**G3. 四轮驱动显式检查清单（A股决策树）**
- 内容：把"政策→资金→估值→情绪"四级作为 L2/L4/L7 的显式闸，与"板块>龙头>资金>图形"并列。
- 价值：弥合"方法论同构但未显式化"的缝隙，让每日主线判断有结构化骨架。
- 动作：**仅作为日报排版模板的章节**，不新增评分字段。属文档/模板层改动，仍需走改动评审（非生产参数）。

**G4. 均线密集 / regime 转换观测器（观察层）**
- 内容：指数 MA 聚合→发散检测，作为多空转换预警（逃生窗口语义）。
- 价值：补全四维健康仪表盘的 Transmission Fidelity / Evidence Quality 维度（现有只盯 Prediction Quality）。
- 动作：观察层 `regime_density_observer.py`，纯观测标注。

**G5. XAUUSD CIO 框架化备注（L1 贵金属 Macro Trade）**
- 内容：把商品期货基本面纲要（供需平衡表/预期差/成本曲线/宏观背离先出场）写入 XAUUSD 引擎的观察备注与决策日志模板。
- 价值：黄金属宏观交易，趋势必须放在宏观大背景下；与 G1 宏观20图、G7 全球资金流联动。
- 动作：更新 XAUUSD 引擎 observation 模板（文档层，不碰策略参数）。

## 三、明确不做（避免越界）

- ❌ 不把 TheMarketMemo 任何指标接入生产评分（违反观察链隔离铁律）。
- ❌ 不在冻结期新增任何评分指标 / 改风控阈值 / 优化分数（8 周纪律期）。
- ❌ 不破解会员墙内容；付费文仅索引。
- ❌ 不用 MA20/60 做实盘个股硬筛（红线）；观察层用指数级宽度属合规例外，已注明。
- ❌ 不自动生成"买/卖"结论；所有框架仅用于"圈候选 + 人工看图"的辅助观察。
