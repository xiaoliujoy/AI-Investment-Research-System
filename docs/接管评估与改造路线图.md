## 四、根因分析

1. **采集逻辑方向相反**：现有采集器是"全市场 TOP100 成交额 + 行业资金流快照"，
   而不是"先定主线板块 → 圈定板块内**全量**股票"。这导致：
   - 板块表为空（行业资金流采集未成功/未持久化）
   - 个股池只覆盖大成交额100只，漏掉中小市值趋势股
   - 个股板块归属缺失，无法反查"属于哪个主线板块"

2. **评分引擎因子与你的硬条件不匹配**：现有 `calc_leader_score` 偏"连板打板"风格
   （连板高度、首板、封板质量、龙虎榜），而你描述的是"趋势+资金"风格
   （20MA>60MA、市值区间、量比、主力净流入）。两者需要融合或重写个股过滤器。

3. **个股关键字段映射失败**：`market_cap` / `volume_ratio` / `main_net_buy` 在
   `collect_stock_daily` 里从 kline 接口取 `mcap` / `volume_ratio` / `main_net_buy`，
   但接口没返回这些字段 → 全空。需要换/补数据源（如东财 spot_em、资金流接口）。

## 五、改造路线图（建议分三阶段）

### Phase A — 打通第一步·板块主线（最高优先级，当前完全断档）
- **A1** 诊断并修复板块资金采集：确认 `stock_fund_flow_industry` 失败原因，
  改为稳定接口（akshare 行业资金流 / 东财行业板块），写入 `sector_daily`
  的 `net_amount` / `amount` / `amount_change_rate`。
- **A2** 新增两个核心查询：① 当日板块资金净流入排名 Top10；
  ② 近5日板块累计净流入排名 Top5。
- **A3** 计算板块资金/成交额"持续放大"（5日趋势斜率或连增天数）。
- **A4** 补全个股→板块归属（`stock_daily.sector`），让"选股必须属于主线板块"可落地。

### Phase B — 接通第二步·个股硬性条件筛选
- **B1** 修复个股采集字段映射：`market_cap` / `volume_ratio` / `main_net_buy` 取值。
- **B2** 新增"硬性条件过滤器"（独立于现有龙头评分）：
  板块 ∈ 主线板块 **AND** 20MA>60MA **AND** 成交额>10亿 **AND**
  市值100-1000亿 **AND** 主力净流入>0 **AND** 量比降序输出。
- **B3** 输出"候选池"到 JSON / 前端列表 / 日报。

### Phase C — 第三步·图形确认辅助 + 全链路整合
- **C1** 用 `high_20d`/`low_20d` + 密集成交区识别，标记"即将突破/刚突破"（仅提示，人工最终确认）。
- **C2** 日报/看板整合完整链路：板块主线 → 候选个股 → 图形提示。
- **C3** 自动化定时任务（每日盘后采集+评分+日报）。
