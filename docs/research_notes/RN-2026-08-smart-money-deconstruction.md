## 0. 为什么写这篇（而非直接做）

来源是一段 2026-07-30 的实盘盘中直播实录（"云聪金融交易分析"）。这类材料最常见的错误用法是
**直接复制成经验交易**：看资金流、看涨停、看盘口、找龙头——最后变成又一套"我觉得"。

本笔记坚持一个原则：**先把高手"看到了什么 / 哪些能机器化 / 哪些必须人工"拆解清楚，
再决定是否值得进系统**。这正是 AI 增强研究体系与经验交易的分界。

---

## Q1：高手到底看到了什么？

实录里反复出现的观察维度，可以归为五类。注意——这些都是**他实时扫描的输入**，不是结论：

| 维度 | 他在看什么 | 实录中的典型表述 |
|------|-----------|------------------|
| **市场情绪** | 外围（美股/韩国）表现、全市场涨跌停家数、连板高度 | "美股跌这么惨 A股没怎么跌，应该能反弹一下" |
| **板块强度** | 当天哪些板块在涨/在跌、跌停股代表什么题材 | "百合花跌停，它代表的有机颜料绝对不能碰" |
| **资金持续** | 某板块/个股连续几日有资金进、开盘一小时后的真实流向 | "半导体底部连续两天有明确大资金进" |
| **价格结构** | 量价配合、突破回抽、吸筹形态、缺口性质 | "长有量跌缩量""下降趋势线突破回抽确认" |
| **风险信号** | 高位连续跌停、龙头断板、无信号破位 | "高位第一个跌停你就可以跑了，舍不得跑后面跑不掉" |

**关键洞察：** 他真正稀缺的能力不是"会买"，而是**五维同时在线扫描 + 风险信号优先**。
他花在"什么不能碰"上的注意力，远多于"买什么"。

## Q2：哪些可以机器化？（AI 适合度评估）

| 能力 | AI 适合度 | 说明 |
|------|----------|------|
| 涨跌停统计 | ★★★★★ | 纯规则计数，数据库 `market_daily` 回填后即可自动产出（情绪温度） |
| 资金连续性 | ★★★★★ | `stock_flow_daily` 已具备持续性基础，做 N 日净流入天数/强度即可 |
| 板块轮动 | ★★★★★ | 受限于 `sector_daily` 板块资金流截至 2026-07-17 仍空（数据补洞优先项） |
| 龙头识别 | ★★★★ | 可规则化（成交额排名+辨识度），但"地位龙头"需人工定性兜底 |
| 题材真假判断 | ★★★ | LLM 可辅助读资讯，但"真产业趋势 vs 短期炒作"仍需人 |
| 盘口博弈 | ★ | 当前无 Level-2 / 逐笔委托，且噪音最大，**排最后、冻结期不投** |

> 结论：前四项（情绪/资金/板块/龙头）是"机器化高 ROI"区，且恰好对应你既有
> `L2 中国 → L4 资金 → L5 龙头` 的增强方向；盘口属 Trading OS 3.0 议题。

## Q3：哪些必须保持人工？

| 能力 | 为什么不能机器化（现阶段） |
|------|---------------------------|
| **政策/产业定性** | "这个政策是真产业趋势，还是短期炒作？"——需要常识、因果链、产业知识，LLM 可辅助但不能替代最终判断 |
| **突发信息解读** | 盘中突发的地缘/政策/公司事件，语义与影响高度依赖语境 |
| **仓位管理** | 涉及个人风险偏好、账户状态，不属于"观察系统"职责 |
| **最终下单决策** | 人负责"定仓位 + 按图确认"，AI 只给候选与风险（与你既有"客观数据→过滤评分→逻辑推演→人工看图"一致） |

> 边界原则：**AI 是超级研究员，不是自动驾驶交易员**。盘口信号只用于"已入选标的的最后一步择时"，
> 绝不能用盘口反向选股（噪音交易陷阱）。

## 收尾：三个待验证假设（指向 `smart_money_momentum_module.md`）

本笔记不重复文档细节，只锚定验证顺序（2026-07-31 用户重排）：

1. **H3（先验证）**：高位连续跌停 = 板块负反馈 → 直接降低回撤，价值极高、验证难度最低。
2. **H2**：赚钱是 Beta 还是 Alpha？须归因分离，与 Cross-Market Observation 共用框架。
3. **H1（绑定 Regime）**：强题材+龙头+资金流 → 上涨概率提升，**仅在 Risk-On/震荡偏多子集内成立**。
