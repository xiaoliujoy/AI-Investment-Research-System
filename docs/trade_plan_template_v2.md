## 系统接线说明（discipline_server）
- 路径：`backend/os_layers/discipline_server.py`，浏览器开 `http://127.0.0.1:8777`
- 盘前计划 `POST /api/plan` 必填：标 ★ 的 入场确认层级 / FOMO自检 / 周期对齐 / 盘后归因守护
- 录入前先过 `trading_constitution.pre_trade_gate()`：BLOCK 级（资产禁止 / 时间违规 / 五问缺 / anticipatory）拒绝记录并回写 `constitution_check`
- 盘后复盘 `POST /api/review` 填 `close_reason`（A/B/C/D）→ 驱动 `thesis_abandonment_rate()`（TAR）
