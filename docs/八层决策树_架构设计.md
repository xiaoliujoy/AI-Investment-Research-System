# 个人A股交易研究操作系统 — 八层决策树架构设计

> 目标定位三连跳：**AI选股 → AI日报 → 个人A股交易研究操作系统（Trading OS）**
> 操作系统每天不是告诉你"买什么"，而是回答八个问题；由数据+AI持续验证、迭代、沉淀经验。

---

## 0. 浓缩哲学（五层 → 八层）

```
宏观(Why)      → 用宏观和产业决定方向
  ↓
产业(Where)    → 用资金和情绪验证方向
  ↓
资金(Who)      → 用价格行为完成交易
  ↓
价格(When)     → 用纪律控制风险
  ↓
纪律(How Much) → 用数据不断优化系统
```

八层 = 把上面五层展开为可每日运行的决策树。

## 3. 各层建设详情

### ① 全球宏观（Global Regime）
- **数据源**：akshare `stock_us_daily`(纳指/SOX)、`macro_usa_*`(FED/10Y)、`currency_rate`(美元/人民币)；需实测沙箱可达性（东财push2被封，可能要走其他域）。
- **产出**：`全球流动性：宽松/中性/收紧` + `科技风险偏好：增强/减弱` + `中国资产：重新定价/中性`，每日一句话结论。
- **建设**：核对 `global_market/data_adapter` 实际调用的接口是否在沙箱可达，替换被封源。

### ② 中国宏观（China Regime）
- **数据源**：人民币、社融、M2、国债收益率、政策会议——部分需手动/半自动（无免费实时API全覆盖）。
- **产出**：`政策/流动性/情绪` 三维评分 → 是否支持风险资产（是/否/谨慎）。
- **建设**：把 `market.py` 升级为"宏观regime评分"，指数位置+广度+政策日历加权。

### ③ 产业趋势（Industry，最重要的一层）★ 新建
- **关键区分**：**产业（投资，6个月维度）≠ 板块（交易，日内/波段）**。日报判"前三产业"，不是"前三板块"。
- **四类驱动**：技术革命(AI/机器人) / 国产替代(GPU/EDA) / 周期涨价(存储/铜) / 政策驱动(低空/数据要素)。
- **方法**：AI主导（非纯量化）。给AI一份"产业观察清单"模板，每日判断未来6个月最值得研究的Top3产业及核心催化。
- **产出**：`未来6个月最值得研究产业：①②③` + 每产业的核心催化与风险。

### ④ 资金共识（Consensus）★ 加模型
- **已有**：step1 板块资金净流入(新浪) + 成交额(同花顺)，90行业同名对齐。
- **新增「共识生命周期」模型**（用户明确要求加入strategy）：
  `事件 → 讨论 → 资金流入 → 赚钱效应 → 一致性 → 高潮 → 退潮`
- **量化信号**：连续N日净流入、涨幅、涨停家数、换手率放大 → AI判定该题材当前处于生命周期哪一步。
- **产出**：`当前共识建立到哪一步？（非简单"情绪高/低"）`，并对主线板块标注生命周期阶段。

### ⑤ 龙头体系（Leader）★ 重建
- **现有问题**：`leader_candidate.py` 偏连板打板，非用户的"趋势+资金"风格。
- **重建为四龙头**：
  - 产业龙头（市占率/技术壁垒第一）
  - 技术龙头（关键突破）
  - 资金龙头（区间净流入/成交额最大）
  - 情绪龙头（涨幅/换手/人气最高）
- **产出**：`产业龙头：X / 资金龙头：Y / 情绪龙头：Z`（四者常不同一家）。
- **依赖**：step2 板块→成分股映射（同花顺数据域爬取，方案A进行中）。

### ⑥ 交易执行（Execution）★ 包壳
- **简化原则**：不堆指标，只回答四问：`可以买？买吗？买多少？何时退出？`
- **已有**：均线/量比/突破区技术字段（tech_fill已算）。
- **建设**：把技术字段包成"四问"决策壳，输出 买点信号(刚突破/即将突破) + 建议仓位区间（仓位由⑦给）。
- **人把关**：最终买卖由用户人工看图确定。

### ⑦ 风险控制（Risk Budget）★ 升级
- **从"止损"升级为"风险预算"**：
  `市场风险(0-?) + 产业风险 + 个股风险 = 综合风险 → 自动仓位%`
- **产出**：`市场风险：20 / 产业风险：10 / 个股风险：30 / 综合：60 → 建议仓位：40%`
- **建设**：每日计算三层风险分，映射为仓位上限，而非固定止损线。

### ⑧ 学习进化（Learning）★ 新建
- **交易日志**：每天保存 `为什么买/卖、结果、盈亏、原因`。
- **月统计**：AI统计 `突破胜率/回踩胜率/追高胜率…` → 系统自动优化。
- **建设**：建 `trade_journal` 表 + 月报统计脚本，闭环"数据驱动"。

## 4. 推荐建设顺序

```
Phase 0  数据底座（进行中）
  ├─ ✅ TDX量价 + 技术字段(ma20/60/量比/突破区)
  ├─ ✅ step1 板块资金(新浪净额+同花顺成交额)
  └─ ⏳ step2 板块→成分股映射(同花顺数据域爬取, 方案A)

Phase 1  OS骨架（把分散模块统一到八层）
  ├─ 建 `decision_tree` 每日输出 JSON（8个问题+答案骨架）
  ├─ 前端看板改为八层结构
  └─ 写 ③/④/⑦ 的 strategy 文档（用户明确要求"加入strategy"）

Phase 2  逐层深化（按价值/可行性排序）
  1. ④ 共识生命周期模型（数据已具备，性价比最高）
  2. ⑦ 风险预算→仓位（纪律，用户重视）
  3. ⑤ 四龙头体系（依赖step2映射）
  4. ③ 产业趋势（AI主导，最难量化，先建模板）
  5. ① 全球宏观数据源复核
  6. ⑧ 学习进化（需先有交易记录）
```
