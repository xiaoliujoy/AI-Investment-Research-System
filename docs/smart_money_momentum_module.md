## 1. 核心假设（待验证，非结论）

> **验证优先级重排（2026-07-31 用户复盘）：** 原序 H1→H2→H3 改为 **H3 → H2 → H1**。
> 理由：投资系统最重要的能力不是找到上涨股，而是**避免进入死亡区域**（H3 价值极高、验证难度最低）；
> 其次要能区分「赚钱靠环境还是靠选股」（H2，与 Cross-Market Observation 同源）；
> H1 最易被市场环境污染（牛市垃圾股也涨、熊市龙头也跌），**必须绑定 Market Regime 才有意义**，故排最后。

| 验证序 | ID | 假设 | 验证方式（解冻后） | 价值 / 难度 |
|--------|----|------|-------------------|------------|
| **①** | **H3** | 高位题材出现**连续跌停** = 板块负反馈信号，其重要性 > 寻找新机会（"先避开死亡区域"） | 统计"龙头/核心股跌停后 N 日板块收益"，验证负反馈领先性 + 作为 AI **负面约束** | 极高 / 低 |
| **②** | **H2** | "外围跌 A股不跟跌"是**情绪 Beta**而非选股 Alpha，需归因分离 | 用 global_history + 个股收益做回归，剥离市场/板块因子后的残差才是 Alpha；与 Cross-Market Observation 共用归因框架 | 极高 / 高 |
| **③** | **H1** | 强题材 + 行业/地位龙头 + 连续 N 日主力净流入 + 量价健康 → 未来 5–20 日上涨概率提升 | 按条件分组 vs 全市场基准，做 N 日收益显著性检验；**前置约束：仅在 `regime = Risk-On / 震荡偏多` 子集内检验**，避免牛熊混淆 | 高 / 中 |

**H1 的 Regime 绑定（关键修正）：** H1 不得无条件成立。正确形态是
`强题材 + 龙头 + 资金流` **∧** `Market Regime ∈ {Risk-On, 震荡偏多}` → 上涨概率提升；
在 `Risk-Off` 环境下即使三者共振也常失效，否则会把"牛市 Beta"误归因为"选股 Alpha"。

**诚信标注：** H1–H3 均来自主播经验陈述，未经数据验证，当前只是假设，不是系统规则。

## 2. 实盘四维 → 可计算信号映射

原始直觉不能直接当买入公式，必须翻译成**可观测、可回测**的信号。

### 2.1 资金流（从"看大小"到"看意图与持续性"）
| 原始直觉 | 系统化指标 | 判断标准 |
|---------|-----------|---------|
| "今天什么资金进得最大" | 主力净流入占比 + 行业资金偏离度（Z-Score） | 板块资金流入显著高于自身历史均值才视为主动攻击，剔除被动配置 |
| "连续两三天有大资金进" | 资金持续性因子 Money Flow Persistence | N 日内主力净流入天数占比 + 累计强度，区分"一日游"与"建仓型" |
| "真实的买单往上砸" | 主动买入率 + 大单成交密度 | 区分吃单（主动）与挂单（被动）；监控大单主动买入频次识别"扫货" |
| "券商涨了证明要维稳" | 国家队/平准行为指纹 | 低位放量 + 逆势拉升 + 特定时间窗 → 政策托底信号（需建特征库） |

> **盲区：** A股 Level-2 存在对倒/滞后欺骗。需结合多日资金轨迹 + 筹码分布交叉验证，不能只看当日。

### 2.2 K线与形态（从"看图说话"到"模式识别 + 概率统计"）
- **威科夫/吸筹：** 波动率收缩（ATR↓）+ 跌缩量/涨放量 + 区间横盘时长 → 聚类识别历史相似形态并回测后续概率。
- **突破回抽确认：** 突破后 3 日内回踩不破突破阳线实体中位，且回踩量能 < 突破量能 50%。
- **缺口分类：** 突破/持续/衰竭缺口按成交量 + 位置自动分类，非一概"有缺口就好"。
- **约束：** 形态是"观察池筛选器"，**必须等资金或量能确认**才进交易，位置到了 K 线没走出来不买（主播原话已体现此纪律）。

### 2.3 量价关系（从"放量缩量"到"供需失衡度量"）
- **量的相对性：** "爆量"= 相对过去 N 日均量的倍数；区分良性放量（换手充分+价格推升）vs 恶性放量（高位巨量阴线滞涨）。
- **量价配合度：** OBV 斜率 / VPVR；价涨 OBV 平走 = 虚假突破；横盘但底部筹码峰上移 = 隐蔽吸筹。
- **流动性阈值（风控第一道）：** 主播"盘子 3 亿不值得看" → 动态过滤：日均成交额 < 阈值、流通盘过小直接剔除。

### 2.4 盘口与微观结构（降优先级）
- 大单追踪（冰山订单/诱多诱空）、分时相对强度 RS（个股 vs 基准指数）、情绪锚点（跌停家数/连板高度）。
- **现状约束：** 当前系统无 Level-2 / 逐笔委托数据（akshare / mootdx 仅日线+波段级）。盘口层**排最后**，冻结期不投入，待 Trading OS 3.0 再议。

## 3. 观察字段规范（Observation Fields：只记录，不影响评分）

冻结期内**不建表、不加列**。以下字段作为 L5 v2 候选输入，解冻后实现：

| 字段 | 含义 | 来源 |
|------|------|------|
| `topic_heat` | 题材强度（政策/产业/新闻催化） | 资讯 + 板块涨幅 |
| `leader_status` | 是否板块行业/地位龙头 | 成交额排名 + 辨识度 |
| `money_persistence` | 资金连续净流入天数/强度 | stock_flow_daily（已具备基础） |
| `breakout_quality` | 突破/回抽/吸筹形态质量评分 | 量价 + 结构规则 |

> 明确：**这些字段当前不进入任何 score 计算**。它们先在每日输出中"打印观察"，积累样本后做分组回测，验证 H1 通过才考虑进 L5 评分。

## 4. 负面约束 / 失败案例库（最重要）

短线高手真正值钱的是"为什么不能买"。以下为**种子观察样本**（来自主播自述，非验证规则，待积累真实案例）：

| 案例 | 表面信号 | 失败原因 | 推导出的最小禁止规则（候选） |
|------|---------|---------|------------------------------|
| **百合花** | 热点 + 涨停 + 资金流入 | 高位情绪退潮 → 跌停扩散 → 板块负反馈，出货出不掉 | 题材退潮阶段禁止低位补涨 / 龙头连续跌停所属板块绝对不碰 |
| **国际复材** | 资金/形态看似好 | 中报预亏、财务极差，纯技术买点失效 | 基本面财务极差（预亏/高负债）直接剔除，不接技术信号 |
| **金东方** | 持仓标的 | 起不来、该砍不砍，破位观察位失效仍犹豫 | 无信号 + 破位观察位失效 → 严格止损，不"再观察一下" |

> 这些案例未来非常适合 AI：把"失败时的资金/K线/量价特征"设为**负面约束条件（Negative Constraints）**，比成功样本更能防回撤。

## 5. 人-AI 边界（与你既有流程一致）

- **AI 负责：** 全市场扫描、多维因子打分、历史模式匹配、风险预警、情绪监控。
- **人负责：** 题材定性（政策/产业理解）、突发信息解读、仓位管理、最终决策。
- **切忌：** 让 AI 完全替代人的盘感做日内高频决策，除非有毫秒级基础设施 + 严格回测策略。当前 AI 定位 = **超级研究员**，不是自动驾驶交易员。

## 6. 与现有八层架构的关系（增强非重构）

既有 `L0 叙事/FLOW/GOLD → L1 全球 → L2 中国 → L3 产业 → L3.5 产业链 → L4 资金 → L5 龙头 → L6 执行 → L7 风险 → L8 学习`。
本模块主要补强 **L4 资金共识 / L5 龙头体系 / L6 执行**，不改变层级拓扑。

**解冻后优先级（用户 2026-07-31 裁定）：**
1. **① Market Regime Engine** — 市场环境决定所有策略胜率，环境错则龙头模式也亏。
2. **② Sector Rotation Engine** — 对应"判环境→选方向"。
3. **③ Stock Selection v2** — 把本模块五阶段逻辑融入 L5（输入：市场状态+板块强度+题材热度+资金流+技术结构 → 候选排序）。
4. **④ 盘口执行 Agent** — 最后做，噪音最大、依赖 Level-2。

## 7. 每日扫描流程（设计稿，冻结后实现）

```
Step 1  市场过滤    Market Regime → 风险状态则停止
Step 2  板块排名    Top 5（资金+题材+趋势综合）
Step 3  龙头池      每板块 Top 3（leader_status）
Step 4  资金过滤    连续3日+净流入、成交额>阈值、趋势向上
Step 5  技术形态    突破/回踩/缩量调整/二次启动（breakout_quality）
Step 6  人工确认    AI 输出：标的+评分+优势+风险+建议观察买点；人定仓位
```

## 8. 解冻后落地路径

1. 先以 **Observation 字段**在现有每日输出中"打印观察"而非评分（零风险）。

3. 验证通过再决定是否进 L5 评分权重；H2 归因贯穿始终。
4. 盘口层（需 Level-2）留待 Trading OS 3.0。
