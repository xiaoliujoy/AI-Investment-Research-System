## RQ-001 · 商品类资产 confidence 是否恒为 1.0（缺乏区分度）
- **提出周**：2026-W31
- **问题**：本周 3 个商品资产（沪铜 / 沪金 / 原油）confidence 全部 = 1.0，无内部区分。若 confidence 对商品恒定，则 confidence_calibration 模块对商品类实质失效。
- **状态**：**部分验证**（2026-W32 更新：原命题证伪，派生新命题）
- **所需证据**：连续多周商品资产 confidence 分布；是否存在 <1.0 的商品样本。
- **当前结论**：
  - ✅ **原命题「恒为 1.0」已证伪**：2026-08-03 三商品 confidence 同时 = 0.6。
  - ⚠️ **派生新命题（待验证）：横截面零离散**。7 个交易日（07-30～08-07）中，沪金/沪铜/原油的 confidence **每一天都完全相同**，从未出现商品之间的内部差异。confidence 在**时间维度会变、横截面无区分力**。
  - 若该派生命题成立，confidence 只能表达「今日整体数据质量」，无法回答「同类资产间该更信哪一个」——与校准模块设计意图可能不符。
  - **仍不下结论**：7 天样本，且 confidence_calibration 模块 n=0 未启动。

## RQ-007 · 每日快照是否存在「结转」（上游未更新导致原样沿用）
- **提出周**：2026-W32（新增）
- **问题**：2026-08-06 与 2026-08-07 两日，4 个资产的 score / state / trend / confidence **全部逐位相同**（A股 71.7、原油 44.2、沪金 65.7、沪铜 66.3）。`generated_at` 分别为 `2026-08-06 22:57:57` 与 `2026-08-07 15:32:47`，属两次独立运行，排除重复写入同一批数据。
- **状态**：**已验证**（2026-W32 当周即证实，可信度：**高**）
- **所需证据**：~~后续是否再次出现~~ → 已通过回溯上游数据表直接证实，无需等待复现。
- **当前结论（结转确认存在，两条链路成因不同）**：

  **① 商品链路：快照时点早于因子落库**

  | 资产 | 08-06 因子 total_score | 08-07 因子**实际值** | AIP 08-07 **记录值** | 判定 |
  |---|---|---|---|---|
  | 沪金 | 65.7 | **66.2** | 65.7 | 记录 = 08-06 |
  | 沪铜 | 66.3 | **66.4** | 66.3 | 记录 = 08-06 |
  | 原油 | 44.2 | **42.8** | 44.2 | 记录 = 08-06 |

  - AIP 快照 `generated_at = 2026-08-07 15:32:47`；同日流水线 15:30 日志记录 `commodity_factor_daily = 2026-08-06`（08-07 因子当时未落库）。
  - 22:39 复查：`commodity_factor_daily` 最新日已为 2026-08-07，三值与记录值**全部不同**。
  - AIP score 与 `commodity_factor_daily.total_score` 为 1:1 映射（08-06 三值完全对应），**因果链闭合**。

  **② A股链路：上游数据至今缺失**
  - `market_daily` **没有 2026-08-07 行**（截至 08-07 22:39 复查仍缺）。
  - 08-06 行 `up_count=2639 / down_count=2416` → 广度 2639/5055 = **52.2%**，正是 08-07 快照写的「上涨家数占比 52%」。
  - A股 08-07 的 score 71.7、广度、主线（煤炭开采加工）**全部沿用 08-06**。

- **影响（须写入后续所有解读）**：
  1. 本周**有效独立观测日 = 6 天（非 7）**，有效行数 = 24（非 28）。`n_days=7` 系高估。
  2. **T+20 验证样本已被污染**：同一份输入被计为两个独立信号，将人为放大 50-70 档权重 → 直接影响 RQ-005。
  3. 修正后真实周环比：沪金 **+9.3**、沪铜 **+2.5**、原油 **−8.6**；**A股无法计算**。
- **处置**：冻结期内**仅登记、不改码**。解冻后建议评估两个方向（二选一或并用）：
  - 为 AIP 快照增加「上游数据日期 == 快照日期」的**新鲜度校验**，不满足则拒绝落库而非静默结转；
  - 将快照生成时点**后移**至商品因子与 `market_daily` 落库之后。
- **待跟踪**：`market_daily` 的 2026-08-07 行是否会被补录；若长期缺失，属采集缺口而非时点问题。

## RQ-008 · A股 score 的单日振幅是「对信息敏感」还是「不稳定」
- **提出周**：2026-W32（新增）
- **问题**：A股 score 出现极大单日跳变 —— 07-30 → 07-31：**29.7 → 83.6（+53.9）**；07-31 → 08-03：**83.6 → 48.6（−35.0）**；08-03 → 08-04：**48.6 → 76.95（+28.35）**。该分数是「当日快照」还是「应具趋势平滑性的判断值」？
- **状态**：待验证
- **所需证据**：≥1 个完整月度 score 序列 + 对应 T+20 收益；确认设计意图（score 定义文档）。
- **当前结论**：
  - 无法区分「对新信息高度敏感（特征）」与「输入噪声主导（缺陷）」。
  - 若属设计内，需明确文档化「score = 当日快照，不承诺跨日稳定性」，否则使用者会误当作趋势判断。
  - 直接影响 RQ-005：分数若在 T 日与 T+1 日相差 50 分，**T+20 收益归因将被噪声主导**，分层验证的有效性存疑。
  - 本周反思（见 Research Note ⑧）已据此认定：07-31 的 83.6「事后方向对了更像运气而非能力」。
