# 第七层：风险控制（Risk Budget）

> 风控不是"设个止损线"，而是"今天该承担多大风险"。仓位来自风险预算，不是感觉。

## 1. 从止损到风险预算
- 旧范式：买入后固定 -8% 止损。
- 新范式：先算**综合风险分**，再反推**仓位上限**。

## 2. 三层风险分
```
市场风险（0-?）  +  产业风险（0-?）  +  个股风险（0-?）  =  综合风险  →  建议仓位%
```

| 维度 | 信号来源 | 高分含义 |
|------|---------|---------|
| 市场风险 | 指数位置 / 波动率 / 广度 / 全球宏观① | 系统性环境差 |
| 产业风险 | 该产业所处共识阶段④（退潮期高分） | 方向在兑现 / 证伪 |
| 个股风险 | 涨幅 / 换手 / 估值 / 突破幅度⑥ | 追高 / 拥挤 |

## 3. 仓位映射（示例）
```
综合风险 < 30  → 仓位 80-100%
综合风险 30-50 → 仓位 50-80%
综合风险 50-70 → 仓位 30-50%
综合风险 > 70  → 仓位 < 30%（或空仓）
```
- 单票上限另设（如单票 ≤ 总仓位 1/3）。

## 4. 与⑥执行层衔接
⑥交易执行的"买多少"直接取本层输出的仓位上限；⑥的"何时退出"仍结合个股技术结构（破位 / 跌破密集成交区）与产业共识退潮信号。
