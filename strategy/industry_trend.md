# 第三层：产业趋势（Industry Trend）

> 这一层是整套系统**最重要的一层**。真正赚钱的不是"今天哪个涨停"，而是"未来半年哪个产业持续获得资金认可"。

## 1. 产业 ≠ 板块（关键区分）
- **产业（Industry）**：投资维度，6 个月以上的资金认可与基本面演进。例：AI、半导体设备、机器人、低空经济。
- **板块（Sector）**：交易维度，日内/波段的热度与资金博弈。例：今天半导体涨、明天军工涨。
- 日报判的是"**前三产业**"，不是"前三板块"。板块是产业的交易映射，会轮动；产业是底层的资金共识方向。

## 2. 产业驱动的四类
| 类型 | 含义 | 示例 |
|------|------|------|
| 技术革命 | 新技术打开新需求 / 降本 | AI、机器人、自动驾驶、固态电池 |
| 国产替代 | 供应链安全驱动的自主化 | GPU、EDA、半导体设备、工业软件 |
| 周期涨价 | 供需错配带来的价格弹性 | 存储、铜、化工、航运 |
| 政策驱动 | 顶层政策直接催化 | 低空经济、数据要素、设备更新 |

## 3. 每日 AI 模板（AI 主导，非纯量化）
给 AI 一份"产业观察清单"，每日输出：

```
未来6个月最值得研究产业（Top3）：
1. 【产业名】核心催化：___  关键验证信号：___  主要风险：___
2. ...
3. ...
当前所处阶段：早期 / 加速 / 分歧 / 兑现 ？
```

- **输入**：全球宏观①结论、中国政策日历②、已有资金共识④的板块聚类。
- **输出**：产业方向 → 指导下游"该在哪些板块里找交易机会"（④⑤）。

## 4. 与上下层衔接
- 上游：①全球宏观（科技风险偏好）、②中国宏观（政策 / 流动性）。
- 下游：④资金共识（产业方向 → 哪些板块在形成共识）、⑤龙头（产业龙头是谁）。
