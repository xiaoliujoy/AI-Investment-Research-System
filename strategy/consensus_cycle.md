# 第四层：资金共识（Consensus）

> 股票上涨不是因为价值，而是因为"越来越多人相信它会涨"。共识 = 人气 + 情绪 + 网络热度 + 资金流入的合力。

## 1. 共识生命周期模型（核心）
```
事件 → 讨论 → 资金流入 → 赚钱效应 → 一致性 → 高潮 → 退潮
```

| 阶段 | 特征 | 量化信号 |
|------|------|---------|
| 事件 | 政策 / 技术 / 业绩催化出现 | 新闻密度上升 |
| 讨论 | 社区 / 研报开始发酵 | 搜索 / 讨论量↑ |
| 资金流入 | 主力开始进场 | 板块净流入由负转正、连续 N 日净流入 |
| 赚钱效应 | 板块内出现赚钱样本 | 涨停家数↑、板块涨幅居前 |
| 一致性 | 市场形成一致预期 | 成交额持续放大、换手率高位、龙头加速 |
| 高潮 | 全面发酵、散户涌入 | 板块成交占比极值、情绪龙头连续涨停 |
| 退潮 | 预期兑现 / 证伪 | 净流入转负、放量滞涨、龙头跳水 |

## 2. 数据底座（已实测可用）
- 板块资金净流入：新浪 `stock_fund_flow_industry`（"净额"列，90 行业）
- 板块成交额：同花顺 `stock_board_industry_index_ths`（"成交额"列，90 行业，同名对齐）
- 辅助：涨停家数（`limit_up_daily`）、换手率（`stock_daily.turnover_rate`）

## 3. 每日判定输出
对每个主线板块（来自 step1 排名）标注生命周期阶段：

```
【半导体】共识阶段：一致性（资金流入第6日 / 成交额放大 / 龙头加速）
【低空经济】共识阶段：讨论→资金流入（事件已出，净流入刚转正）
```

- 不是简单判"情绪高 / 低"，而是判"**建立到哪一步**"，用于决定：参与、持有、还是警惕退潮。

## 4. 与 step1 衔接
step1 的「净流入 Top10 / 5日累计 Top5 / 成交额放大 Top10」是共识模型的**输入信号**；本层在其上做**阶段分类**与**持续性确认**。
