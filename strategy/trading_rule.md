# 交易系统规则

## 一、概述

本交易系统基于以下核心理念：

> **资金决定方向，板块决定赔率，龙头决定收益弹性，价格行为决定交易时机，风控决定长期收益。**

输出：明确的交易信号（参与/等待/空仓）。

---

## 二、交易决策树

```
每日盘前决策流程：

1. 判断市场阶段
   │
   ├─ 退潮期 → 空仓
   │
   ├─ 启动期/修复期 → 轻仓试错（20-40%）
   │
   ├─ 发酵期 → 积极介入（40-60%）
   │
   ├─ 加速期 → 重仓龙头（60-80%）
   │
   ├─ 高潮期 → 持有但开始减仓（70-90%→50-70%）
   │
   └─ 分歧期 → 保留核心，清仓跟风（30-50%）

2. 选择板块
   │
   ├─ T0 主线（评分>80） → 重仓参与
   │
   ├─ T1 强主线（评分70-80） → 积极参与
   │
   ├─ T2 次主线（评分60-70） → 适度参与
   │
   └─ T3/T4 冷门 → 回避

3. 选择龙头
   │
   ├─ 绝对龙头（评分>85） → 重仓
   │
   ├─ 核心龙头（评分70-85） → 积极参与
   │
   ├─ 次龙（评分55-70） → 轻仓
   │
   └─ 跟风（评分<55） → 回避

4. 风控检查
   │
   ├─ 风险等级 > 60 → 不参与
   │
   ├─ 已有持仓亏损 > 7% → 止损后再开新仓
   │
   └─ 总仓位已达上限 → 不再加仓
```

---

## 三、参与条件

### 3.1 什么情况下参与

必须**同时满足**以下所有条件：

| 序号 | 条件 | 判断标准 |
|------|------|----------|
| 1 | 市场不是退潮期 | 市场情绪分 > 25 |
| 2 | 有明确主线板块 | 至少1个板块评分 > 70 |
| 3 | 有可参与的龙头 | 绝对或核心龙头评分 > 70 |
| 4 | 风险等级 < 60 | 非极高风险 |
| 5 | 未达仓位上限 | 当前仓位 < 建议仓位 |
| 6 | 有可用资金 | 不在满仓状态 |

### 3.2 最佳参与场景

| 场景 | 条件 | 仓位 | 预期 |
|------|------|------|------|
| **A 确定性最高** | 加速期 + T0主线 + 绝对龙头 | 70-90% | 主升浪 |
| **B 高性价比** | 发酵期 + T1主线 + 核心龙头 | 50-70% | 捕获主升 |
| **C 试错机会** | 启动期 + 新方向 | 20-30% | 试仓 |

## 四、等待条件

### 4.1 什么情况下等待

满足以下**任一**条件即进入等待状态：

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | 市场情绪分 25-40 | 市场不明确 |
| 2 | 无板块评分 > 60 | 无明确主线 |
| 3 | 龙头断板分歧 | 方向不明 |
| 4 | 持仓在观察中 | 不追加 |
| 5 | 等待止损后 | 先处理持仓 |
| 6 | 盘中波动剧烈 | 等待收盘确认 |

### 4.2 等待期可以做什么

```
等待期不是什么都不做，而是：

1. 盘后研究
   - 复盘当日走势
   - 分析板块轮动
   - 筛选潜在龙头

2. 跟踪观察池
   - 维护龙头候选列表
   - 记录板块变化
   - 关注新方向

3. 模拟验证
   - 验证交易规则
   - 回溯历史数据
   - 优化评分模型
```

## 五、空仓条件

### 5.1 什么情况下空仓

满足以下**任一**条件即清仓：

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | 退潮期确认 | 市场情绪分 < 25 |
| 2 | 系统性风险 | 跌停 > 30家 |
| 3 | 总亏损达 -10% | 强制空仓 |
| 4 | 连续3次止损 | 说明判断有误 |
| 5 | 龙头批量跌停 | 市场崩溃 |
| 6 | 重大事件驱动 | 不可控因素 |

### 5.2 空仓后可以做什么

```
空仓是交易的一部分，不是失败。

空仓期间：
1. 休息调整心态
2. 学习研究
3. 等待下一个周期
4. 绝不抄底（退潮期无底）
```

## 六、交易时间轴

### 6.1 每日时间表

| 时间 | 动作 | 内容 |
|------|------|------|
| 08:30-09:00 | 盘前准备 | 查看隔夜外盘、消息面 |
| 09:00-09:15 | 集合竞价 | 观察竞价量能、方向 |
| 09:15-09:25 | 确认开盘 | 市场情绪、板块方向 |
| 09:25-09:30 | 决策 | 是否参与、买什么、买多少 |
| 09:30-10:00 | 开盘观察 | 确认判断、择机介入 |
| 10:00-11:30 | 盘中持有/观察 | 不轻易操作 |
| 11:30-13:00 | 午盘休息 | 复盘上午、调整策略 |
| 13:00-14:30 | 下午观察 | 确认持续性 |
| 14:30-15:00 | 尾盘决策 | 是否加仓/减仓/持有 |
| 15:00-15:30 | 盘后复盘 | 记录、总结、准备次日 |

### 6.2 关键时间点

```
09:25 竞价结束 → 确认市场方向
09:30 开盘 → 观察前15分钟
10:00 定势 → 判断全日
14:30 尾盘 → 决策是否持有过夜
15:00 收盘 → 盘后分析
```

## 七、交易纪律

### 7.1 铁律（不可违反）

1. **绝不抄底** — 退潮期没有底
2. **绝不加仓亏损股** — 只加仓盈利股
3. **绝不因为亏损而加仓** — 越跌越买是散户思维
4. **绝不追高非龙头** — 龙头追高是勇气，跟风追高是愚蠢
5. **绝不在退潮期持股** — 退潮期现金为王
6. **绝不忽视止损** — 止损是交易的成本

### 7.2 软律（尽量遵守）

1. 只做主线，不做杂线
2. 只做龙头，不做跟风
3. 仓位匹配市场阶段
4. 每日复盘记录
5. 定期回测策略
